
## Условие задачи

Даны целые числа, указывающие количество **часов (0–24)** и **минут (0–60)**. Вычислить время в минутах, когда часовая и минутная стрелки встретятся.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало программы.**
2. Подключить необходимые библиотеки и установить русскую локализацию.
3. Объявить переменные:
   - `h` — количество часов;
   - `m` — количество минут;
   - `t` — время встречи стрелок в минутах.
4. **Ввести количество часов** `h`.
5. **Ввести количество минут** `m`.
6. Проверить правильность введённых данных: часы должны находиться в диапазоне от 0 до 24, а минуты — от 0 до 60.
7. Если данные введены правильно, вычислить время встречи стрелок по формуле:

   `t = (60.0 * h + m) * 12.0 / 11.0`

8. **Вывести время встречи стрелок в минутах**, округлив результат до двух знаков после запятой.
9. Если данные введены неправильно, вывести сообщение **«Ошибка ввода данных»**.
10. **Конец программы.**

## 3. Результаты работы программы

### Пример 1. Корректный ввод данных

Входные данные:

```text
Введите часы (0-24): 3
Введите минуты (0-60): 0
```

Расчёт:

**`t = (60 * 3 + 0) * 12 / 11 = 196.36`**

Результат:

```text
Время встречи стрелок: 196.36 минут
```

### Пример 2. Некорректный ввод данных

Входные данные:

```text
Введите часы (0-24): 25
Введите минуты (0-60): 10
```

Результат:

```text
Ошибка ввода данных
```
